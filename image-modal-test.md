# Image Modal Test Page

This page demonstrates the new image modal functionality.

## How It Works

All images in posts and pages are automatically converted to clickable thumbnails. When you click on an image, it opens in a full-screen modal with:

- Smooth fade/zoom animations
- Keyboard navigation (arrow keys, ESC to close)
- Touch/swipe support on mobile
- Image captions from alt text
- Gallery mode for multiple images

## Features

- **Click any image** to open it in a modal
- **Use arrow keys** to navigate between images
- **Press ESC** to close the modal
- **Swipe on mobile** to navigate
- **Hover over thumbnails** to see the preview effect

## Styling

The modal matches your site's purple gradient theme with:
- Purple gradient buttons and descriptions
- Smooth hover effects on thumbnails
- Dark overlay with blur effect
- Responsive design for all screen sizes

All existing markdown images work automatically - no code changes needed!
